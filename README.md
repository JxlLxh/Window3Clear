# Window3Clear by JxlLxh

**Window2Clear的升级版，原名Window2Clear++，分为A、R、V三个分支。**

**An upgraded version of Window2Clear, originally named Window2Clear++, divided into three branches: A, R, and V.**

> 轻量级 Windows 窗口透明度管理工具 —— 纯 Win32 API 与 GDI 手绘，无任何第三方 UI 库依赖。

## 📖 简介

Window3Clear 旨在为你提供最顺手、最原生的窗口透明度控制体验。无论是摸鱼、多任务对比，还是纯粹的视觉偏好，你都可以通过鼠标拖拽、快捷键或自动化特效，随心所欲地调节任何 Windows 应用程序的透明度。

## ✨ 核心特性

- **🛡️ 终极防窥三件套（`v19.1-beta` 新增）**：
  - **紧急遮罩**：`Ctrl+Alt+S` 一键全屏纯黑遮挡，应对突发查岗。
  - **前台优先级**：快捷键永远优先调节当前最顶层窗口，无视锁定目标。
  - **面具防误触**：可自由开关是否在调节透明度时强行拉起面具遮挡，告别摸鱼时的“突然霸屏”。
- **🎭 面具模式**：调透明前全屏拉起伪装窗口，在底层偷偷修改后撤回，完美视觉欺骗。
- **🎨 主题切换**：支持深色/浅色主题，适配日夜使用环境。
- **⌨️ 全局快捷键自定义**：所有核心快捷键均可在设置界面一键录制修改。
- **💻 双架构支持**：原生提供 `x86_64` 与 `x86` (32-bit) 双版本支持。
- **纯原生体验**：仅依赖 Windows 原生 API，极低内存占用，类 macOS 亚克力质感。
- **配置持久化**：所有设置与窗口状态自动保存，重启无缝恢复。

## ⌨️ 默认快捷键（均可在设置中修改）

| 快捷键 | 功能说明 |
| :--- | :--- |
| `Ctrl + Alt + P` | 鼠标拾取目标窗口（带高亮框提示） |
| `Ctrl + Alt + S` | **紧急全屏黑屏遮罩（按 ESC 退出）** |
| `Ctrl + Alt + B` | 极速触发一次面具防窥伪装 |
| `Ctrl + Alt + H` | 老板键（隐藏/恢复当前前台窗口） |
| `Ctrl + Alt + M` | 摸鱼模式（将当前列表内所有窗口变透明） |
| `Ctrl + Alt + 0` | 一键恢复**所有**窗口的透明度至 100% |
| `Ctrl + Alt + ← / →` | 快速减/加前台窗口透明度（步长 20） |
| `Ctrl + Shift + 1/2/3/4` | 快捷将前台窗口设至 25% / 50% / 75% / 100% |

## ⚠️ 注意事项

本项目采用纯 C++ 编写，无第三方外部依赖。
                        
Linux、MacOS 暂不支持，对此我们深感歉意。部分 UWP 应用、全屏游戏、任务管理器由于系统权限限制，可能无法调整透明度。若需调整管理员权限运行的窗口，本程序也需要**以管理员身份运行。**

*预告：Linux 支持预计在 `v19.x-pro` 引入。*

版本 `v19.1-beta`，保留所有权利。

## 🖥️ 环境要求：

- Windows 10 / 11
- MSYS2 环境下的 MinGW/GCC (建议 GCC 10.0 以上)
- 双击运行 `build.bat` 或终端执行 `./build` 即可一键编译出 64 位和 32 位双版本程序（需提前安装 `mingw-w64-i686-gcc`）。
