# 🪟 Window3Clear by JxlLxh

> 轻量级 Windows 窗口透明度管理工具 —— 纯 Win32 API 与 GDI 手绘，无任何第三方 UI 库依赖。

## 📖 简介

Window3Clear 旨在为你提供最顺手、最原生的窗口透明度控制体验。无论是摸鱼、多任务对比，还是纯粹的视觉偏好，你都可以通过鼠标拖拽、快捷键或自动化特效，随心所欲地调节任何 Windows 应用程序的透明度。

## ✨ 核心特性

- **🎭 防窥面具模式（加急新增）**：一键全屏伪装。调透明度时，先用伪装窗口（如 VS Code）全屏盖住 2 秒，在底层偷偷修改完毕后再悄悄撤走，老师/老板绝对看不出破绽！
- **纯原生体验**：仅依赖 Windows 原生 API，极低内存占用。
- **类 macOS 亚克力质感**：主界面采用底层 `SetWindowCompositionAttribute` 实现亚克力半透明毛玻璃效果。
- **智能句柄追踪**：基于「进程名+类名」锁定目标，目标窗口意外重建或重启也不会丢失控制。
- **全局热键支持**：快捷调节前台窗口透明度，支持老板键与摸鱼模式。
- **自定义渐隐 & 呼吸灯**：可自定义渐隐时长（1~120秒）及目标透明度，或开启平滑呼吸灯特效。
- **配置自动持久化**：所有窗口的透明度状态、面具设置、自启设置等自动保存至 `%APPDATA%\Window3Clear\config.ini`。

## ⌨️ 默认快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| `Ctrl + Alt + P` | 鼠标拾取目标窗口（带高亮框提示） |
| `Ctrl + Alt + B` | **极速触发一次面具防窥伪装** |
| `Ctrl + Alt + H` | 老板键（隐藏/恢复当前前台窗口） |
| `Ctrl + Alt + M` | 摸鱼模式（将当前列表内所有窗口变透明） |
| `Ctrl + Alt + 0` | 一键恢复**所有**窗口的透明度至 100% |
| `Ctrl + Alt + ← / →` | 快速减/加前台窗口透明度（步长 20） |
| `Ctrl + Shift + 1/2/3/4` | 快捷将前台窗口设至 25% / 50% / 75% / 100% |

## ⚠️ 注意事项

本项目采用纯 C++ 编写，无第三方外部依赖。
                        
Linux、MacOS 暂不支持，对此我们深感歉意。部分 UWP 应用、全屏游戏、任务管理器由于系统权限限制，可能无法调整透明度。若需调整管理员权限运行的窗口，本程序也需要**以管理员身份运行。**

预告：Linux 支持预计在 v19.x-pro 引入。Windows 32-bit 支持预计在v19.x-beta（x>0）引入。

版本 v19.0-beta，保留所有权利。

## 🖥️ 环境要求：
- Windows 10 / 11
- MSYS2 环境下的 MinGW/GCC，建议 GCC 10.0 以上（如果你是下载源码编译的话）
- 在 Windows 上双击运行 `build.bat` 或终端执行 `./build` 即可一键编译。
