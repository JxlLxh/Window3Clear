\# 🪟 Window3Clear V18 Pro



一款极致轻量的 Windows 窗口透明度控制工具。基于 C++ 和 Win32 API 纯原生开发，无任何第三方依赖，体积小巧，秒开即用。



\## ✨ 功能特性



\- \*\*🎨 现代极简 UI\*\*：采用 GitHub Dark 暗黑主题，自绘无边框窗口，支持系统托盘常驻。

\- \*\*🔍 实时搜索\*\*：内置进程搜索框，快速定位并锁定目标窗口。

\- \*\*🌗 一键调节\*\*：通过滑块或预设按钮（25% / 50% / 75% / 100%）实时调整任意窗口透明度。

\- \*\*📌 置顶与穿透\*\*：支持将目标窗口固定在最前，或开启“鼠标穿透”模式（看视频、查资料神器）。

\- \*\*⌨️ 全局快捷键\*\*：

&#x20; - `Ctrl + Alt + ← / →`：调节前台窗口透明度

&#x20; - `Ctrl + Alt + 0`：恢复前台窗口

&#x20; - `Ctrl + Shift + 1/2/3/4`：快速应用 25% / 50% / 75% / 100%

\- \*\*💾 状态记忆\*\*：自动按「进程名+类名」记住每个窗口的透明度状态，重启程序自动恢复。

\- \*\*🖱️ 托盘控制\*\*：点 `X` 隐藏到托盘，右键托盘可彻底退出并恢复所有窗口透明度。

\- \*\*⏳ 定时渐隐\*\*：支持 5 秒渐隐至 50% 的平滑动画（在“更多”菜单中）。



\## 🛠️ 如何编译



本项目\*\*不需要依赖任何资源文件（无 `.rc`）\*\*，直接使用脚本即可一键生成图标并编译。



1\. 确保安装了 MinGW (GCC) 环境，并配置了环境变量（推荐使用 MSYS2）。

2\. 将代码克隆到本地：

&#x20;  ```bash

&#x20;  git clone https://github.com/JxlLxh/Window3Clear.git

&#x20;  cd Window3Clear

&#x20;  ```

3\. 双击运行 build.bat，或者在终端中执行：

&#x20;  ```bash

&#x20;   ./build

&#x20;  ```

&#x20;  编译成功后，当前目录会自动生成 Window3Clear\_V18\_Pro.exe。



注：源码包含了动态生成精美图标的代码（gen\_ico.cpp），由 build.bat 自动调用，无需手动准备 .ico 文件。

\## ⚠️ 注意事项



部分 UWP 应用、全屏游戏、任务管理器由于系统权限限制，可能无法调整透明度。

若需调整管理员权限运行的窗口，本程序也需要以管理员身份运行。
